# CR8 Mesh Schema v2 — the map as a debugging roadmap
Drafted 2026-10-20 by MUZI from the MUZI × Copilot discussion (see COPILOT-DISCUSSION-2026-10-20.md). Merges MUZI's 4-point proposal with Copilot's corrections. Status: DRAFT for Taheed/Copilot review. The v1 data (mesh-context.json, snapshot 2026-09-17) migrates into this shape without losing facts — unverified v1 statuses land as `unprobed`, not as claims.

## The one rule
**No node or edge is "live" without evidence.** A status is an observation with a timestamp, a verifier, and a receipt — or it decays to `unprobed`.

## Four layers (never one blob)
1. **Topology** — nodes + typed edges. Slow-changing facts: what exists, what it runs on, what it calls.
2. **Observation** — probe definitions and their results: the evidence layer.
3. **Operations** — alerts as work items with owners and unblock conditions.
4. **Lineage** — snapshot provenance: where this data came from, when, generated by what.

## Lineage block
```json
{
  "snapshot_id": "cr8mesh-2026-10-20",
  "base_snapshot_id": "cr8mesh-2026-09-17",
  "generated_at": "2026-10-20T00:00:00Z",
  "scanner": {"name": "...", "version": "...", "ran_on": "lenovo|muzi-vm|cloud"},
  "source_status": "fresh|stale",
  "node_count": 0, "edge_count": 0
}
```
Counts are **computed from the arrays at write/render time** — never hand-typed (kills the 125/295 vs 36/34 mismatch).

## Node
```json
{
  "id": "lenovo",
  "kind": "host|service|cloud_project|storage|workspace|asset|external_dependency|mount|agent|network_segment",
  "name": "Lenovo",
  "owner_lane": "lenovo|cloud|taheed|external|unknown",
  "observed_status": "live|degraded|down|unprobed",
  "status_confidence": "verified|indirect|unknown",
  "last_verified_at": null,
  "verified_by": null,
  "evidence_ref": null,
  "freshness_policy": {"stale_after_seconds": 7200, "decay_to": "unprobed"},
  "probes": [
    {"type": "ssh|http|gcloud|rclone|fs_scan|api|db|tailnet",
     "command": "...", "last_success_at": null, "last_failure_at": null,
     "exit_code": null, "output_ref": null, "retry_plan": "..."}
  ],
  "triage_order": 1
}
```
One canonical record per node. Summaries (counts, rollups) are derived, never stored twice.

## Edge
```json
{
  "id": "e-001", "from": "lenovo", "to": "sshd",
  "type": "runs_on|calls|stores_in|depends_on|exposes|ingress",
  "status": "verified|broken|blocked|unprobed",
  "probe_command": "...",
  "last_verified_at": null, "evidence_ref": null
}
```
Troubleshooting = start at the symptom node, walk upstream edges in `triage_order`, run each edge's probe, stop at the first broken or unprobed edge. Observe → fix → re-probe.

## Alert (work item, not a label)
```json
{
  "alert_id": "alert-009", "entity_id": "lenovo",
  "severity": "blocker|high|medium|low",
  "issue": "SSH port 22 returns no banner",
  "root_cause_hint": "sshd not installed/running",
  "fix_target": "Lenovo: install/start openssh-server",
  "owner_lane": "lenovo",
  "unblock_condition": "sshd answers on port 22",
  "status": "open|blocked|fixed",
  "evidence_ref": null, "last_updated_at": null
}
```
The current 18 legend rows (mesh-ops/ALERT-LEGEND.md) convert 1:1 into these objects; the legend stays as the human-readable render.

## Migration notes (v1 → v2)
- v1 `services[].status` values (live/down/degraded from Sept 17/Oct 1) become `observed_status` **only** where MUZI re-verified live on 2026-10-20 (Google Drive, Supabase); everything else migrates as `unprobed` with `status_confidence: unknown` and the v1 value preserved in lineage notes.
- v1 `punch_list` items become alerts with owner lanes; "LEAVE" (BRAIN inside BRAIN) becomes status `fixed` with issue annotated as ruled-no-action.
- v1 `conduit` figures move to lineage as historical probe stats, not current state.
